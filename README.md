# MyWeatherAPP  

#### 📢 전 세계 도시의 날씨를 검색하여 알아볼 수 있으며, 동시에 캘린더도 지원하는 어플리케이션
🖥️ 개발환경 : Java, Android Stuido, SQLite, Weather API

<br>

1. 일정 확인이 가능한 캘린더 기능 (CalendarActivity.java)
2. API 연결 (Function.java)
3. 전 세계 도시 검색 및 해당 도시의 습도, 기압 등 정보 제공 (MainActivity.java)
4. 일정 등록 및 삭제 등 일정 관리 기능 (TodoAcitivity.java)
5. Database 관리 (DbHelper.java)
